# Marketplace Listing Draft — Live NHL Scores

## Name
Live NHL Scores

## Short tagline (optional, if Marketplace supports one)
Live NHL, AHL, and ECHL scores on every button.

## Description

Track live hockey scores directly on your Stream Deck — NHL, AHL, and ECHL. Each button follows one team and refreshes automatically every 30 seconds — no browser tab, no app switching, no missed goals.

See the away score, home score, and current period/time at a glance. Buttons flash in your team's primary color when they score. Before puck drop, see the matchup and scheduled start time; after the final buzzer, catch the result with "Final," "Final/OT," or "Final/SO" labeling.

Search by team or city name across all three leagues, or browse by league and division — 94 teams total (32 NHL, 32 AHL, 30 ECHL), refreshed live from each league's own API so new and relocated teams show up automatically. Press any button to jump straight to the game's recap or gamecenter. On an off day, the button shows your team's next scheduled matchup instead of a dead end. Want a different look? Pick a custom background color and opacity for each button in settings. No account or API key required — scores come from each league's public API.
