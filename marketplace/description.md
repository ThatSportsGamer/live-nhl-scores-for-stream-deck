# Marketplace Listing Draft — Live NHL Scores

## Name
Live NHL Scores

## Short tagline (optional, if Marketplace supports one)
Live NHL scores on every button.

## Description

Track live NHL scores directly on your Stream Deck. Each button follows one team and refreshes automatically every 30 seconds — no browser tab, no app switching, no missed goals.

See the away score, home score, and current period/time at a glance. Buttons flash in your team's primary color when they score. Before puck drop, see the matchup and scheduled start time; after the final buzzer, catch the result with "Final," "Final/OT," or "Final/SO" labeling.

Press any button to jump straight to NHL Gamecenter for that game. No account or API key required — scores come from the NHL's public API.
